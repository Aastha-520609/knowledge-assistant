# AI Engineering Documentation Assistant

A production-style RAG (Retrieval-Augmented Generation) system that answers questions over pre-indexed AI engineering documentation — LangGraph, LangChain, FastAPI, and Qdrant.

---

## Architecture

```
User Query
    │
    ▼
[Streamlit UI]  ──  source filter (optional)
    │
    ▼
[Retriever]  ──  loads ChromaDB, applies metadata filter, returns top-6 chunks
    │
    ▼
[Chain]  ──  builds prompt with context + question, calls Groq LLM
    │
    ▼
[Answer + Citations]  ──  returned to UI, citations shown in expander
```

---

## Project Structure

```
Assistant/
├── app/
│   ├── sources.py      # defines all documentation sources (sitemap URLs, metadata tags)
│   ├── ingest.py       # loads, chunks, embeds, and stores docs into ChromaDB
│   ├── retriever.py    # loads ChromaDB and returns a retriever with optional source filter
│   ├── chain.py        # builds prompt, calls LLM, returns answer + citations
│   └── ui.py           # Streamlit chat interface
├── data/
│   └── chroma/         # persisted vector store (generated by ingest.py)
├── .env                # GROQ_API_KEY, USER_AGENT
├── requirements.txt
└── README.md
```

## Tech Stack

| Component       | Tool                          |
|----------------|-------------------------------|
| LLM            | Groq — `llama-3.1-8b-instant` |
| Embeddings     | HuggingFace `all-MiniLM-L6-v2` (local, no API) |
| Vector Store   | ChromaDB (persisted to disk)  |
| Doc Loading    | LangChain SitemapLoader       |
| Chunking       | RecursiveCharacterTextSplitter |
| UI             | Streamlit                     |
| Orchestration  | LangChain LCEL (pipe syntax)  |

## Phases Completed

### Phase 1 — Basic RAG MVP
- Loads documentation pages via sitemap
- Cleans HTML (removes nav, footer, scripts) using BeautifulSoup
- Splits into chunks (1000 chars, 150 overlap)
- Generates embeddings using `all-MiniLM-L6-v2` (runs locally)
- Stores vectors in ChromaDB (persisted to `data/chroma/`)
- Retrieves top-6 relevant chunks per query
- Generates grounded answers via Groq LLM
- Displays citations in collapsible expander
- Streamlit chat UI with message history

### Phase 2 — Multi-Source Knowledge Base
- Added 4 documentation sources: LangGraph, LangChain, FastAPI, Qdrant
- Each chunk tagged with `source_type` and `source_display` metadata at ingest time
- Metadata filtering at retrieval time — query only the selected source or all sources
- Dynamic source dropdown in UI — adding a new source to `sources.py` auto-adds it to the dropdown
- Improved citation format: `SourceName — URL`
- All sources stored in one ChromaDB collection, separated by metadata tags

## Setup

### 1. Install dependencies
```bash
pip install -r requirements.txt
```

### 2. Set environment variables
Create a `.env` file:
```
GROQ_API_KEY=<your_groq_api_key>
USER_AGENT=rag-assistant/1.0
```

### 3. Ingest documentation
```bash
python -m app.ingest
```
This crawls all 4 documentation sources, chunks them, generates embeddings, and saves to `data/chroma/`. Run once — vectors persist on disk.

### 4. Run the app
```bash
streamlit run app/ui.py
```

## How It Works

**Ingestion (offline, run once):**
1. `sources.py` defines each documentation source with its sitemap URL and filter prefix
2. `ingest.py` crawls each sitemap, strips HTML noise, splits into chunks
3. Each chunk is tagged with `source_type` (e.g. `"langgraph"`) and `source_display` (e.g. `"LangGraph"`)
4. All chunks are embedded and stored in ChromaDB

**Query (runtime, every question):**
1. User types a question and optionally selects a source filter in the UI
2. `retriever.py` loads ChromaDB, applies the metadata filter if set, returns top-6 chunks by cosine similarity
3. `chain.py` joins the chunks into a context string, fills the prompt template, calls the Groq LLM
4. Answer and citations are returned to the UI and displayed
